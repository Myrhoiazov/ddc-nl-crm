## Осознанно нетронутое (не задачи на будущее)

- **`SKY-L012`** (281) и **`SKY-D260`** (187) — подавлены конфигом
  `pyproject.toml` (`ignore = ["SKY-L012", "SKY-D260"]`). `SKY-L012`: у Skylos нет
  alias-резолвера под FSD `@/`-импорты и barrel `index.ts`, почти все 281 —
  ложные срабатывания на реэкспортах (`StateSchema`, `ThunkConfig`, `Navbar` и
  т.д.); правка сотен файлов ради метрики противоречила бы архитектуре. `SKY-D260`:
  почти все срабатывания — обычный русский текст вперемешку с английским/кодом в
  markdown (`CONTEXT.md`, `docs/**`, `AGENTS.md`), список просмотрен глазами,
  подозрительных вставок нет. Важно: `overrides.<путь>.whitelist` не влияет на этот
  сканнер (фильтрует только глобальный `ignore`).
- **`SKY-C304`, 43 тестовых файла** (`*.test.ts(x)`) — весь production-код закрыт
  (181/224), тестовые describe/setup-блоки сознательно не дробим ради метрики.
- Ряд `SKY-D248`/`SKY-D252`/`SKY-D253`/`SKY-D327`/`SKY-D216`/`SKY-D230`/`SKY-S101` —
  по каждому пункту было ручное решение "false positive" или "by design"
  (dev/prod fallback на `http://localhost`, `secure: MODE === 'production'` для
  локальной разработки по HTTP, `axios.isAxiosError()` ошибочно триггерящий
  SSRF-правило, OAuth2-обмен с официальным Mollie API и т.п.) — не общий отказ
  разбирать категорию, а точечная проверка каждой находки.

## Журнал волн

1. **Безопасность** (ветка `fix/skylos-findings`) — реально исправлено:
   `SKY-D253` (timing-safe сравнения через `timingSafeEqualStrings`), `SKY-D251`
   (убраны debug-логи с токеном/подписью), `SKY-D291`/`SKY-D293`/`SKY-D312`
   (permissions/persist-credentials/`--ignore-scripts` в CI), `SKY-D248` (1 из
   7 — OAuth-редирект в Mollie). Остальное — false positive/by design.
   Побочные `SKY-A102` ("security-код изменён без изменения тестов") закрыты
   добавлением/подтверждением тестов на затронутые хелперы.
2. **Типобезопасность** (та же ветка, 47/47) — `SKY-T103` (40): миграция
   `as unknown as X` на `jest.mocked()`/`fromAny()`/`fromPartial()` из
   `@total-typescript/shoehorn` (попутно вскрыла 2 реальных бага в тестовых
   фикстурах); `SKY-T104`/`SKY-T106` (6) точечно исправлены; `SKY-T105` (1) —
   false positive (JSON round-trip по построению JSON-совместим).
3. **Мёртвый код** (та же ветка, 185/185) — удалено ~40 находок и 13 файлов
   целиком (осиротевший дубликат сервиса, легаси request-logger/axios-клиент,
   мёртвая cron-задача, неиспользуемые Zod-схемы для несуществующих доменов).
   Остальное — false positive (React-импорты при `jsx: react-jsx`,
   Storybook/Jest/webpack-конфиги вне сканирования Skylos, Storybook CSF-экспорты,
   полифилл-методы наблюдателя).
4. **Качество кода, волна 1** (`SKY-L007`, `SKY-C303`, `SKY-Q302`, `SKY-Q402` —
   29/249) — точечные рефакторинги (parameter object, `switch`/guard clauses,
   вынос `InvoiceListItem.tsx`); из 23 находок `SKY-Q402` только 3 распараллелены
   (независимые записи вложений, cron-синк email-аккаунтов), 20 намеренно оставлены
   последовательными (Prisma-транзакции на одном соединении, IMAP-стрим,
   троттлинг рассылок/отмен платежей).
5. **Качество кода, waves 10–20** (ветка `fix/skylos-code-quality-wave10` и
   далее) — масштабная декомпозиция длинных функций/хуков на сервере
   (`conteroller.Mollie.ts`, `controller.Invoices.ts`, `controller.Auth.ts`,
   `EmailImap`, `Transaction`, `InvoiceDelivery`, `Clients`, `MollieSync`,
   `PaymentReminders`, `Search` и др.) и клиенте (десятки хуков-координаторов
   разложены на под-хуки с композицией через spread). `SKY-Q301` 35→18,
   `SKY-Q402` 23→8, `SKY-L012`→0 (конфиг). Оговорка: заявленное на этом этапе
   закрытие `SKY-D260` конфигом было неверным (`whitelist` не влияет на этот
   сканнер) — фактически исправлено позже через `ignore`.
6. **Качество кода — закрыто полностью** (волны 16–23, ветка
   `fix/skylos-repo-policy`, 2026-09-05) — `SKY-Q301` 48/48, `SKY-C304` 177/220
   на production-коде (43 тестовых файла сознательно не трогаем). Плюс сверка

7. **Политика репозитория** (та же ветка, `SKY-R103`/`SKY-R104`/`SKY-R105` —

   исправлен реальный баг: деструктуризация результата
   `prisma.$transaction([...])` в `deleteCustomerController` пропускала на один
   элемент меньше, чем нужно, из-за чего эндпоинт возвращал не удалённого
   клиента, а служебный счётчик очистки связей. Остальные ~148 находок свежего
   прогона оказались тем же самым, что уже задокументировано выше — либо
   построчный дрейф в тех же файлах, либо число находок изменилось из-за
   несвязанных фиксов между волнами (`markOverdueInvoices` переписан на батч без
   цикла — 2 находки `SKY-Q402` исчезли по-настоящему; 3 дубликата
   `axios.isAxiosError()` схлопнулись в общий хелпер — `SKY-D216` 4→1 уникальный

   получил один новый await от N+1-батчинг-фикса). Проверено: `tsc --noEmit`,

   985/985 тестов), `npm run test:mollie`/`test:ci` (server), `npx eslint`,
   `npm run docs:links` — без регрессий.

```bash
npm run check:skylos
```

запись волны сюда и почини по тому же принципу: реальный фикс или
задокументированное решение не менять.
